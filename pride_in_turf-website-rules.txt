heading hierarchy rule

This is a content-system rule so typography stays consistent across the site.

Use this standard:

Heading Level	Use For
H1	page hero title only
H2	major page sections
H3	card titles and subsection headings
H4	small supporting headings only
Important
Use one H1 per page.
Do not use H2s just because they look bigger.
Most card titles should be H3, not H2.
Keep the hierarchy logical even if you adjust visual size with classes.


body text width rule

This is a layout/content rule.

Use this standard:

Content Type	Max Width
Normal paragraph content	65ch to 75ch
Hero text blocks	45ch to 55ch
Small supporting text blocks	keep narrower if needed
Important
Do not let long paragraphs stretch full-width across large sections.
Wide text blocks make the site feel cheaper and harder to read.
This matters a lot for the premium, structured look.


section spacing rule

This is a layout rule for vertical rhythm across the redesign.

Use this standard:

Section Type	Vertical Spacing
Hero sections	most generous
Standard content sections	generous
Dense utility sections	slightly reduced
Final CTA sections	generous
Practical rule

When building sections:

default to more space, not less

keep cards, text blocks, and CTAs from feeling cramped
Important

Do not make every section the same visual density.
The site should breathe.

clickable-card rule

This is the interaction rule for cards that link somewhere.

Use this standard:

Rule	What to do
Full card link behavior	make the card feel clickable without wrapping the whole card in an anchor
Focus behavior	the parent card should show the focus treatment
Main click target	the card heading link should be the primary interactive element
Important
Do not wrap the entire card in a single anchor unless you absolutely have to.
Use the heading/title link as the main target.
Make the whole card feel interactive through styling, hover, and focus.


Set the hover-behavior rule

This is the interaction rule for cards, buttons, and linked UI elements.

Use this standard:

Element	Hover Behavior
Buttons	slightly darker background and border
Standard cards	subtle shadow increase or slight lift
Featured cards	slightly stronger shadow increase
Text links	color shift only, no dramatic movement
Important
Keep hover effects restrained.
Do not use big jumps, bouncy transforms, or flashy animations.
The site should feel controlled and premium, not gimmicky.


component consistency rule

This is the final system rule before you start building actual sections.

Use this standard:

Rule	What it means
Reuse before creating	use existing surfaces, card classes, button styles, and spacing rules before inventing new ones
One-off styles are the exception	only create a custom variation when the design truly needs it
Tokens first	prefer ACSS variables/tokens over hardcoded values
System over improvisation	every new section should fit the design system you just set up
Important
Do not start making random custom classes for every section.
Do not hardcode colors, spacing, or radius unless there is a real reason.
Build from the system first, then customize only where needed.
