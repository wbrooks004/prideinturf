# Coding Standards

## Naming

Use lowercase.

Use kebab-case.

---

## CSS

BEM naming.

Example:

hero

hero__content

hero__heading

hero__actions

hero--large

---

## HTML

Semantic only.

Never use div soup.

Prefer:

section

article

nav

aside

header

footer

main

---

## Accessibility

Every image needs alt text.

Proper heading hierarchy.

Keyboard accessible.

Visible focus states.

---

## Performance

Lazy load images.

Avoid unnecessary JavaScript.

Minimize DOM depth.

Use responsive images.
