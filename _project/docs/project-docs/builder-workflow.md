# Builder Workflow

## Order

1. Create CPT

2. Create ACF

3. Populate content

4. Build Etch Component

5. Build Template

6. Assign Template

7. Test Responsive

8. Test Dynamic Data

9. Verify Accessibility

10. Run Lighthouse

---

## ACSS First

Always use:

Stacks

Clusters

Grid

Gap variables

Spacing variables

Typography variables

Never build custom CSS first.

---

## Components

If repeated twice:

Create a component.

---

## CSS

Avoid custom CSS unless absolutely necessary.

Prefer:

- utility classes
- ACSS variables
- component classes
