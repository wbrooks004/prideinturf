# Pride In Turf

## Project Overview

Pride In Turf is a premium lawn care company serving Metro Atlanta. The website is a custom-built WordPress marketing site focused on lead generation, trust building, and long-term scalability.

The site is built using

- WordPress
- Etch WP
- Automatic.css (ACSS v4)
- Advanced Custom Fields Pro
- WS Form Pro
- WPCodeBox
- Custom Post Types
- Dynamic Templates

The goal is not simply to recreate a marketing website but to build a scalable content system that can continue growing for years.

---

## Core Objectives

- Fast page loads
- Excellent SEO
- Fully dynamic content
- Minimal plugin dependency
- Consistent design system
- Maintainable architecture
- Easy client editing
- Strong conversion optimization

---

## Build Philosophy

Everything should be

- reusable
- dynamic
- component based
- easy to maintain
- ACSS first
- Etch native whenever possible

No page should contain duplicated structures that could become reusable components.
