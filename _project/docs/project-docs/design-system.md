# Design System

## Philosophy

Premium.

Simple.

Confident.

Modern.

Professional.

The site should feel closer to premium SaaS than traditional lawn care websites.

---

## Layout

Containers

Standard content width

Hero width

Full width backgrounds

Consistent vertical spacing.

---

## Typography

One heading family.

One body family.

Clear hierarchy.

Avoid excessive font weights.

---

## Colors

Use only defined brand colors.

Never introduce arbitrary colors.

All colors should use ACSS variables.

---

## Buttons

Primary

Secondary

Text link

Buttons must have:

- hover
- focus
- disabled

states.

---

## Cards

Cards should be reusable components.

Examples:

- service cards
- review cards
- article cards
- update cards
- CTA cards

---

## Icons

Use a consistent icon family.

Avoid mixing icon sets.

---

## Images

Use modern aspect ratios.

Lazy load.

Proper object-fit.

Responsive sizes.

---

## Shadows

Subtle.

Premium.

Avoid harsh shadows.

---

## Radius

Use consistent border radius throughout the project.

---

## Animation

Small.

Fast.

Purposeful.

Avoid excessive motion.

Respect reduced-motion preferences.
