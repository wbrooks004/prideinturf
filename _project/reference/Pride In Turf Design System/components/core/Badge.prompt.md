Small uppercase pill — service tags, "Since 2005" chips, category labels on cards.

```jsx
<Badge variant="primary">Free Consultation</Badge>
<Badge variant="accent" icon={<Icon name="shield-check" size={14} />}>Licensed program</Badge>
```

Variants: `primary` (green tint), `accent` (orange tint), `neutral` (gray, default), `inverse` (translucent white, for dark/photo surfaces). Not a notification badge/counter — for that, compose a small circle manually.
