Sunken-surface branch card — name + optional "Primary" badge, description, address, click-to-call phone. **Only for the two real branches (Hoschton, Atlanta)** — per readme.md, every other city is a service area, not a location, and must not get this component or standalone NAP treatment.

```jsx
<LocationCard
  isPrimary
  label="Hoschton"
  address="1900 GA Hwy 211, Hoschton, GA 30548"
  phone="+1 833-388-8873"
  description="Serving Hoschton, Braselton, Winder, Auburn, Dacula, Buford, Gainesville, and surrounding Northeast Georgia."
/>
```
