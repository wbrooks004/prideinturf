Checkmark bullet list — used in the hero ("Warm weather, cool weather, and mixed lawn care programs…") and anywhere a short set of value props needs to read as a scannable list rather than prose.

```jsx
<InfoList
  onDark
  items={[
    'Warm weather, cool weather, and mixed lawn care programs',
    'Services focused on turf health, weeds, pests, disease, and root-zone support',
    'Serving Metro Atlanta and Northeast Georgia',
  ]}
/>
```
