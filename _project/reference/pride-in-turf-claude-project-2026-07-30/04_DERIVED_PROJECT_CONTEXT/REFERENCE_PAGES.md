# Reference Pages

> **Status:** DERIVED. Page roles come from the architecture SOT. React pages and bundled HTML are visual references only.

## Authoritative page roles

| Page | Role | Key rule |
|---|---|---|
| Homepage `/` | Primary positioning and navigation hub | Remove false location/service signals |
| About `/about-us/` | Company story and trust | Do not invent unsupported history or credentials |
| Contact `/contact/` | Quote/contact flow | Use verified contact details and WS Form Pro |
| Careers `/careers/` | Careers hub | Use verified openings only |
| Lawn-care programs `/lawn-care-programs/` | Broad commercial programs hub | Program structure must match approved service model |
| Atlanta `/lawn-care-atlanta/` | Real branch page | Branch NAP/schema allowed |
| Hoschton `/lawn-care-hoschton-ga/` | Real branch page | Branch NAP/schema allowed |
| Duluth `/lawn-care-duluth-ga/` | Service-area page | No branch NAP/schema/location framing |
| Lawn-service parents/children | Canonical service content | Follow coding sheet plus architecture hierarchy |
| Referral `/refer-a-friend/` | Referral landing page | Follow referral SOT and preserve policy/recommendation distinctions |
| Blog `/blog/` | Article archive | Keep useful articles; do not bulk redirect by default |
| Legal pages | Privacy and terms | Legal review required for substantive changes |
| HTML sitemap `/sitemap/` | User-facing sitemap | Keep, but noindex |
