The repeating "eyebrow → heading → subhead" pattern seen on every section of the live site.

```jsx
<SectionHeading
  eyebrow="Lawn Care Programs"
  heading="Choose the right program for your turf type and conditions."
  subhead="Four program options for warm weather, cool weather, mixed, and select lawn care needs."
/>
<SectionHeading eyebrow="Request a Quote" heading="Ready for a healthier lawn?" align="center" onDark />
```

`align="center"` also caps max-width for a centered CTA band. `onDark` swaps text colors for use over the ink surface or a hero photo.
