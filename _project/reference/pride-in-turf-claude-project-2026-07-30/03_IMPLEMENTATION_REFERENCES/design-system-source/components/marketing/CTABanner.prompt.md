Centered, full-width closing band — the "Ready for a healthier lawn?" pattern that ends every page on the live site.

```jsx
<CTABanner
  heading="Ready for a healthier lawn?"
  subhead="Request a quote and Pride In Turf will help point you toward the right program or service."
  cta={<Button variant="primary">Request Quote</Button>}
/>
```
Variants: `inverse` (ink, default), `brand` (full green), `light` (sunken neutral — use when it follows another dark section).
